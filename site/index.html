How to install a plugin

Plugins are Go binaries distributed as GitHub release assets. Installation downloads the platform binary, validates the stdin/v1 contract, and registers the plugin locally.

01 · Find

Pick a plugin

Browse the catalog above. Each entry links to the plugin's GitHub repository, where you can read its README and find the latest release tag.

02 · Install

Run one command

Pass the Go module path and a release tag. prunesh downloads the matching platform binary and validates the contract before registering it.

prunesh plugin install github.com/prunesh/prunesh-gh@v1.0.0

03 · Done

Hooks pick it up

No restart needed. The next command the agent runs is intercepted by the new plugin. Verify with prunesh plugin list.
